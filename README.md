## Мастерская из 1100 браузерных инструментов

На GitHub Pages опубликован каталог из **1100 интерактивных инструментов**:

- **1000 практических операций** на 100 тематических страницах: обработка текста, очистка и сравнение данных, кодирование, JSON/CSV/XML, URL, инструменты разработчика, даты, математика, цвета и конвертация единиц.
  Открыть: https://ivanivorontsov-sudo.github.io/tools-audit/web-tools.html
- **100 шуточных калькуляторов** в «Лаборатории прикладного абсурда» — интерактивные расчёты, которые науке не нужны, но настроение поднимают.
  Открыть: https://ivanivorontsov-sudo.github.io/tools-audit/funny-tools.html
- **Умный поиск по мастерской:** https://ivanivorontsov-sudo.github.io/tools-audit/search.html

Основные операции выполняются прямо в браузере; введённые значения не отправляются на сервер мастерской.
